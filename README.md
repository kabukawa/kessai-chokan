# わが国の決済システムの鳥瞰図

日本銀行『決済システムレポート』（2024年9月）の図表1を、ブラウザだけでたどれる一枚の図にした公開ページである。全銀ネットや日銀ネット当預系のように複数の決済が通る機関は、一つにまとめて線でつないである。

数値、制度の最近の動き、各インフラの説明は、同じレポートの本文を短く整理した `決済システムレポート2024_解説.md` と、ページ右欄の文章に入っている。図と文章の整理には AI を使っている。原文との違い、抜け、誤りがあり得る。確認は、日本銀行が公表した [全文 PDF](https://www.boj.or.jp/research/brp/psr/data/psr240910.pdf) で行う。商用目的で原文を転載・複製する場合は、日本銀行決済機構局への相談が必要である。

## 画面の使い方

ページを開くと、四つの列（何を決済するか、取引・指図・照合、清算、決済）が並ぶ。箱をクリックすると、その経路だけが濃くなり、右の欄に、つながる仕組みとレポートの最近の動きが項目名で並ぶ。項目名を開くと文章が出る。

ヘッダー左のアイコンは絞り込み、右のアイコンは説明の開閉である。開いているあいだボタンは金色で、閉じると紺地に金色の欄の印が出る。「お金の流れ」を切ると、選んだ線の上を動く金貨が止まる。

「地球儀」タブは、同じ箱と線を日銀ネット当預系を中心にした球に置いたものである。ドラッグで向きを変える。左上の「何を決済するか」で一つ選ぶと、そのつながりだけが出る。左のチェックは列の図の表示を選び、地球儀のドロップダウンは球の上のネットワークを一つに絞る。この二つは別々に動く。

## 手元で開く

`決済システム鳥瞰図.html` をブラウザで開く。サーバも追加のライブラリも要らない。公開サイトの入口 `index.html` は、このファイルと同じ内容である。行ごとに分けた静的な図は `決済システムの鳥瞰図.svg` である。

## 公開の更新

GitHub Pages は、`github-pages` ブランチのルートを HTTPS で公開する。図や解説を直したあとは、そのブランチへ push する。反映には数分かかることがある。

公開 URL にはリポジトリ名が付く。アカウント `kabukawa` の `kabukawa.github.io` は、履歴書サイト（https://resume.kabukawa.biz/）として `master` から公開済みである。決済の図をそこへ置くと履歴書が置き換わるため、このリポジトリを分けている。

## ページが出ないとき

`github-pages` ブランチのルートに `index.html` があるかを見る。Pages の公開元は、そのブランチの `/` である。設定が違うと 404 になる。図が古いときは、ブラウザの再読込でキャッシュを捨てる。
